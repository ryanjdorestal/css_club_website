The bypass is for emergencies (a broken CI blocking a fix), not for everyday work: even the admin opens a PR.
Pushes from the admin's machine straight to `main` are accepted with a "bypassed rule violations" warning —
read it as a reminder.

Command-line equivalent, for the record:

```bash
gh repo edit --description "…" --enable-issues --enable-discussions --enable-wiki=false --enable-auto-merge --delete-branch-on-merge --default-branch main --add-topic …
gh api -X POST repos/<owner>/<repo>/rulesets --input ruleset.json     # the JSON is in docs/archive/context/44_RUN11_LOG.md
gh label create "good first issue" --color 40A33F --description "…" --force   # × 12
```
