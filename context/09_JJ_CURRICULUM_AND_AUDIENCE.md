# 09 — John Jay curriculum and audience

Checked during the session against the John Jay bulletin and the major checklist.

## The major

**Computer Science and Information Security (B.S.)** — John Jay College of Criminal
Justice, CUNY. It is a security-flavored systems curriculum, not a web curriculum.

Required CSCI (Fall 2024 checklist):
CSCI 271 Introduction to Computer Science · 272 Object-Oriented Programming ·
274 Computer Architecture · 360 Cryptography and Cryptanalysis · 373 Advanced Data
Structures · 374 Programming Languages · 375 Operating Systems · 377 Computer
Algorithms · 379 Computer Networking · 411 Computer Security and Forensics ·
412 Network Security and Forensics.
Electives (choose 1): 362 Databases and Data Mining · 376 Artificial Intelligence ·
380 Selected Topics · 404 Internship in MIS.
Also in the catalog: 171 Introduction to Python, 172 Intro to Data Analysis,
273 Graphics and Interface Programming, 275 Linux System Administration and Security,
279 Data Communications and the Internet.

Languages named in descriptions:
- **CSCI 271**: "Computer problem solving and programming in a high level language
  **such as C++** are introduced. … basic data types, operators and expressions, control
  structures, functions, arrays and pointers."
- **CSCI 272**: no language named (OOP, ADTs, inheritance, polymorphism, event-driven).
- **CSCI 171**: Python (by title).
- **No web course, no JavaScript, no Java, no React in the required sequence.**

## What that implies (agreed in the session)

- "Use what they learn in school" can't be satisfied for a *website*: they learn C++,
  and C++ doesn't build websites. The constraint was flipped: the club site is where a
  John Jay student touches the web stack the major skips — that's a recruiting pitch,
  and it's literally what the old site's copy promised ("React, Python, CSS/HTML/JS"
  workshops).
- C++ belongs in workshops and in the WebAssembly track (04), where it's honest.
- The security tilt (360, 411, 412, Cyberhounds CTF) is the club's real differentiator
  among CUNY CS clubs. Cyberhounds should be visible, not buried.
- Python is the one language that's both in the catalog and on the platform's back end;
  it's the natural second on-ramp.

## Audience, measured (see 02)

- Board: ~5 people, does ~all the committing.
- App submitters: students with 1–2 shipped apps (Ryan has seen several).
- Public: prospective members, John Jay admin, sponsors, other CUNY clubs (tenant #3+).
- Discord: 661 members (2021 figure). YouTube: 49 subs, 11 videos.
